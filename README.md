# Snake-Game

I have made a simple web-based Snake game using HTML, CSS, and JavaScript. In this game, the snake is represented by a green box that moves inside a grid. The player controls the direction of the snake using the arrow keys to guide it toward the food, which is represented by a red box. Each time the snake eats food, it grows longer. If the snake touches the border or itself, the game ends and displays “Game Over.” The game also includes a live score tracker.   
I have used AI to fix some errors.
